## 1. Investigated Ecosystems
- **Open Interpreter:** Flexible terminal computer use, but lacks default-deny security governance. (Adapted: governed execution patterns).
- **OpenHands (OpenDevin):** Containerized software engineering sandbox. (Adapted: sandboxing concepts).
- **Letta (MemGPT):** Paged core and archival memory blocks. (Adapted: categorized memory persistence).
- **LangGraph:** Graph-based state machine orchestration with checkpointing. (Adapted: state transition validation and task recovery).
- **Model Context Protocol (MCP):** Anthropic standard for stdio/SSE tool and resource discovery. (Adapted: SEED's MCP tool adapter).
- **Ollama:** Local model runner (`qwen3:4b`). (Adapted: default offline-first model gateway).
